# AI 职业行情研究报告（2026-10 快照）

> 数据窗口：2025-10 → 2026-10 · 语料：4,142 条岗位帖（去重后），其中 AI 相关 2,619 条，含可解析薪资 658 条
> 来源：HN「Who is hiring?」13 期月度帖（3,985 帖）、RemoteOK API（99）、WeWorkRemotely RSS（81）；GitHub / arXiv / Hugging Face 作生态佐证
> 本报告全部数字可由仓库 pipeline 复现；规则与口径见「方法与来源」页

## 1. 摘要（TL;DR）

1. **AI 已经不是「一个岗位类别」，而是招聘的主体**。HN Who is hiring 中 AI 相关帖占比从 2025-10 的 57.8% 升至 2026-08 的 72.5%，一年内抬升约 15 个百分点。
2. **招聘方要的不再是「会调 API」**。出现率最高的技能是 Python（28.3%）、React（27.7%）、TypeScript（26.4%）这类通用工程底座；而真正的溢价集中在 **评估（+10.4%）、RAG（+11.1%）、向量检索（+12.4%）、解决方案架构（+11.9%）**——即「把 LLM 做成可靠产品」的稀缺能力带。
3. **桌面筹码技能不产生溢价**。Python / React / TypeScript / AWS / Kubernetes 高频出现但溢价在 ±5% 内甚至为负——它们是入场券，不是加分项。
4. **薪资地标**（自述区间中值口径）：LLM 应用 $190k、Agent $200k、Infra/MLOps $180k、AI 产品 $197k；旧金山/纽约 $200k > 伦敦 $173k > 柏林 $109k；知名大厂名单公司 $250k vs 自述早期创业公司 $150k。约 3/4 帖子不披露薪资——本报告对缺失显式标注，不做插补。
5. **最陡的转型斜率在相邻岗位**：LLM 应用 ↔ Agent 技能重合度最高；数据工程 → RAG / AI Infra 是低重修成本的路径。

## 2. 数据与方法

- **采集**：Algolia API 逐期抓取 13 个「Ask HN: Who is hiring?」月度帖的全部顶层评论（3,998 条，剔除自由职业版与过短帖）；RemoteOK 官方 API 单次全量（本期仅返回 99 条，其中 89 条 AI 相关）；WWR 公开 RSS 4 类目（81 条）。抓取时间 2026-10-04，来源 URL/时间/条款记录于 `SOURCE_MANIFEST.json`。
- **结构化**：HTML 清洗 → 启发式抽取公司/职位/地点（40 城市词典 + 远程标记）→ 101 项技能正则字典（含别名，可逐条溯源）→ 10 类岗位关键词分类（标题权重 4×、正文 1×，AI 门槛整词匹配）→ SHA-256 去重。
- **薪资**：仅解析带货币标识的区间；非美元按静态汇率粗折；时薪 ×1750h、月薪 ×12；超出 $25k–$900k 合理域丢弃；**无披露 → 缺失，绝不插补**。658/2,619（25.1%）有真实区间。
- **统计**：溢价 = 含技能帖薪资中位数 − 同池不含帖中位数；岗位重合度 = 各画像 Top 技能集 Jaccard；噪音候选 = 高频（≥5%）∧ 溢价 ≤3% ∧ 特异性 ≤0.35（分布熵归一）。

## 3. 发现一：AI 岗位到底在招什么

**趋势**：AI 相关帖占比 2025-10 为 57.8%，2026-02 达 63.1%，2026-08 峰值 72.5%，2026-10 回落至 65.9%（当月帖数仍偏少，存在截尾效应）。绝对量上，月均 AI 帖约 195 条。

**岗位结构**（主分类，多标签口径见画像页）：

| 岗位族 | 帖数 | 占 AI 帖 | 有薪样本中位（区间中值） |
|---|---|---|---|
| AI 销售/增长 | 259 | 9.9% | $175k |
| Agent 工程师 | 232 | 8.9% | $200k |
| LLM 应用工程师 | 220 | 8.4% | $190k |
| AI Infra/MLOps | 162 | 6.2% | $180k |
| 数据工程（AI） | 140 | 5.3% | $170k |
| AI 产品经理 | 104 | 4.0% | $197k |
| AI 解决方案 | 94 | 3.6% | $205k |
| ML 研究/算法 | 60 | 2.3% | 样本不足 |
| AI 安全 | 39 | 1.5% | 样本不足 |
| 通用 AI 工程（未细分） | 1,563 | 59.7% | $180k |

两点解读：其一，**59.7% 的 AI 帖是「AI 优先的通用工程岗」**——不设专职 AI 头衔但要求 AI 工程能力，这意味着「全民 AI 化」而非小圈子；其二，专职岗位中 Agent 超过传统 LLM 应用成为最大招聘族，与开源生态信号一致（GitHub 上 MCP servers 91.0k★、LangGraph、CrewAI 高速增长）。

**各画像岗位的高频核心要求**（出现率）：LLM 应用岗要 Python(38%)/RAG(34%)/LLM Eval(26%)/Prompt Engineering(31%)；Agent 岗要 Function Calling/Tool Use(35%)/Agent 编排(30%)/MCP(16%)；MLOps 岗要 Docker(36%)/K8s(25%)/推理优化(19%)/量化(11%)。完整列表见画像页。

## 4. 发现二：技能溢价与噪音

**溢价榜**（Δ% = 含技能 vs 不含的薪资中位差；n = 薪资样本）：

| 技能 | Δ% | n | 置信度 | 解读 |
|---|---|---|---|---|
| JavaScript | +13.9% | 23 | 中 | 反直觉：会交付完整产品全栈能力稀缺 |
| Kafka | +12.5% | 17 | 低 | 数据侧规模化能力 |
| 向量数据库 | +12.4% | 8 | 低 | RAG 基建核心，样本小 |
| 解决方案架构 | +11.9% | 41 | 高 | 面客能力溢价稳定 |
| 产品管理 | +11.1% | 69 | 高 | 工程师中的产品力溢价 |
| RAG | +11.1% | 25 | 中 | 已从噱头变为硬技能 |
| Anthropic/Claude API | +11.1% | 22 | 中 | 多模型能力优于单模型 |
| PyTorch | +11.1% | 16 | 低 | 训练侧门槛 |
| Prompt 注入防护 | +11.1% | 9 | 低 | AI 安全稀缺溢价 |
| **LLM 评估/Evals** | **+10.4%** | **54** | **高** | **本期最值得关注的可习得溢价** |

**噪音侧（桌面筹码）**：Python(−3.9%)、React(−6.7%)、TypeScript(−3.4%)、AWS(−2.7%)、Kubernetes(−1.4%)、GCP(−2.0%)、OpenAI API(+1.4%)、Elasticsearch(+2.6%)、Airflow(−1.4%)——高频出现、溢价归零甚至为负。注意口径：**「噪音」指「不构成差异化」，不等于「不需要」**；它们是入围门槛。

三句提醒：溢价是相关不是因果（高溢价技能从业者往往也在大厂/高成本城市）；样本 <20 的条目只当方向感；**评估（Evals）是「高置信 + 可自学 + 岗位要求增长」三者交集的最佳候选**。

## 5. 发现三：薪资的地理、形态与诚实声明

- **城市**（帖内提及，样本 ≥29）：旧金山 $200k、纽约 $200k > 西雅图 $160k、奥斯汀 $165k、多伦多 $170k、伦敦 $173k >> 柏林 $109k。柏林样本多为欧洲初创自述，含非美元折算。
- **办公形态**：远程/可远程 $175k（1,206 帖）vs 未注明 $195k（1,088 帖）——披露远程的岗位薪资略低，与「远程岗更多来自初创」一致。
- **公司类型**：大厂/AI 实验室名单命中仅 18 帖（$250k 中位）vs 自述融资阶段初创 154 帖（$150k）——差距 ≈ 1.67×，但大厂样本小，仅当方向。
- **诚实声明**：约 75% 帖子无可解析薪资；披露存在自选择偏差（透明文化公司/竞争激烈岗位更愿意写）；不含股权；非美元为粗折算。**本报告所有薪资读数应作「区间感」，不是精确行情。**

## 6. 发现四：谁在密集招 AI 岗

帖次数 ≥3 的公司 60 家。头部为持续多月在招的中小型公司（Coder、ML6、Tandem Health、Starbridge、LiveKit、PermitFlow、Freeform 等 9–12 帖），而非传统大厂——与 HN 社区构成一致：**AI 招聘主力是产品 AI 化中的成长期公司**。大厂（Google/Meta/OpenAI 等）在名单命中仅 18 帖，因它们主要走自有招聘渠道而非 HN。完整榜单与方向拆分见公司热度页。

## 7. 发现五：岗位重合度与转型斜率

画像页的技能集 Jaccard 重合度显示：

- **LLM 应用 ↔ Agent** 重合度最高（核心技能大面积共享：Python、Function Calling、结构化输出、评估）——LLM 应用工程师转向 Agent 成本最低。
- **数据工程 ↔ RAG / MLOps** 共享管线与基建技能——数据工程师是 RAG 岗位的天然跳板。
- **AI 产品 ↔ LLM 应用** 共享评估与 RAG 认知——工程师转 AI PM 或反向迁移都不需要推倒重来。
- **AI 安全**与各岗重合度都低但溢价显著（Prompt 注入防护 +11.1%）——适合安全背景者切入，竞争者少。

## 8. 真实机会（需求 × 差异化矩阵）

- **最高性价比**：LLM 评估（Evals）——高置信溢价、可自学、在 LLM 应用/Agent/RAG 三族岗位通用。
- **稀缺供给带**：AI 安全（需求绝对量小但几乎无供给竞争）、推理优化/vLLM（MLOps 内的溢价子技能）。
- **饱和带（避免只押注）**：纯 Prompt Engineering、单模型 API 调用——已桌面化。
- **结构性机会**：传统后端/数据工程师 + 3 个月 RAG/评估补差 = 进入 Agent/RAG 岗位的最短路径（路线生成器已内置该背景预设）。

## 10. 局限

样本偏英文技术社区，不代表中文市场与传统行业；规则分类存在「通用 AI 工程」大桶（59.7%）；薪资自选择偏差；溢价的辛普森效应；跨月重复发帖会推高公司热度计数。全部规则与数据可复现，欢迎审计与改进。
